## Plan: Refactor Member QR Code To Use Member ID

### Goal
Change the QR code content in `src/pages/MemberProfile.tsx` so the generated QR encodes the member's database ID instead of a slug-based public profile URL.

### Findings
- `MemberProfile` still uses the route param `slug` to load the profile via `api.getMemberBySlug(slug)`. That should remain unchanged because public profile navigation is still slug-based.
- The QR code content is currently built at line 94 as `memberUrl = slug ? https://rannncrew.netlify.app/member/${slug} : ""`.
- The QR component receives that value at line 364: `<GenerateQRCode ref={qrRef} text={memberUrl} />`.
- `Member` has a stable `id: string` field, and attendance records reference `attendance.member_id -> members.id`, so QR attendance scanning should use `member.id`.
- `handleDownload` currently names the file from `slug`, which can remain user-friendly unless you want the downloaded filename to use the member ID too.

### Implementation Steps
1. In `src/pages/MemberProfile.tsx`, replace the slug URL QR value with a member-ID-based QR payload.
2. Use a structured JSON string instead of a raw ID so future scanner logic can validate the QR type/version:

```ts
const memberQrPayload = member
    ? JSON.stringify({ v: 1, type: "attendance_member", memberId: member.id })
    : "";
```

3. Replace `<GenerateQRCode ref={qrRef} text={memberUrl} />` with `<GenerateQRCode ref={qrRef} text={memberQrPayload} />`.
4. Remove `memberUrl` if it is no longer used anywhere else in `MemberProfile.tsx`.
5. Keep the route, profile display slug, and `handleDownload` filename unchanged unless a member-ID filename is explicitly desired.
6. Run `npm run build` to verify TypeScript and production build.

### Optional Follow-Up
- When implementing admin QR scanning, parse the scanned text as JSON and require:
  - `payload.v === 1`
  - `payload.type === "attendance_member"`
  - `payload.memberId` is present
- Then insert or upsert attendance with `member_id: payload.memberId` and the selected `event_id`.
